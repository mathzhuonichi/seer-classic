# Branding source

The official Seer logos and favicon, as downloaded; `manifest.json` records where each file came from. The icons of the Tauri
desktop app (removed on 2026-10-24) were upscaled from `seer-official.png`, the 64-by-64 frame of the official favicon. The game
never requests these files, so they are not in the web build or the browser package.
