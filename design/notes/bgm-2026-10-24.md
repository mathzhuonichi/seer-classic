# Background music outside battle (2026-10-24)

User request, 2026-10-24: 添加对战以外的背景bgm. Until now only the battle theme played (`battle-audio.md`). This note
records which music the 2009-2013 Flash client played on its maps, how it chose it, where the files come from, and the
remake's design. Scope: music only, no new sound effects.

## Summary

- The original client plays one looped theme per map, named by the map's `sound` attribute in its map table and fetched
  from `resource/map/sound/<id>.mp3`. The 2013-07-06 core DLL (the only archived one) holds that table and the player code.
- The game's 156 regions sit on 153 original maps, which use **90 themes**. 150 maps take their theme from the 2013 table;
  the three maps added later take it from the current official table, and two of those three are period files too.
- The official Flash resource server still serves every one of the 90 files under the period name. No archive holds a
  2009-2013 copy to compare bytes with; the files' own metadata matches the period tool chain (below).
- The files ship unchanged: 25,845,055 bytes (24.6 MiB), 3,702 s of music, ignored by Git like the other audio and copied
  into the browser package with the rest of `public/`.

## How the original client chose the music

Source: the 2013-07-06 `RobotCoreDLL.swf` (Wayback snapshot `20130706235627` of
`http://seer.61.com/dll/RobotCoreDLL.swf?hir2eh3c`, SHA-256 `ad513c3a…a5df0`, kept in
`../analysis/engravings-2013/sources/`). The release DLL is the client's seven-byte header plus a zlib stream
(`net/DLLLoader.as`); decoded, it is a CWS SWF (SHA-256 `6b1fc3da…f6be5288`). FFDec 26.3.0 decompiled its scripts; nothing
was executed.

- `com.robot.core.SoundManager.playSound()` takes the current map's ID through `MapManager.getResMapID` (an instanced map
  above `ID_MAX` uses its style map) and reads `MapXMLInfo.getBgSoundIdByMapId`, the map's `@sound` attribute.
  - The same ID as the playing theme: nothing changes, the theme plays on.
  - A different ID: `stopSound` lowers the channel's volume by 0.03 every 30 ms (about one second from full volume), stops
    it, and then loads the new theme and plays it from the start.
  - No theme playing (after `stopSound`): the theme starts again from position 0.
  - An empty ID: the map SWF's own embedded `sound` symbol plays at volume 0.2. None of the game's maps needs this.
  - Themes loop (`play(position, 99999)`); `ClientConfig.getMapSound(id)` is `<resource root>map/sound/<id>.mp3`.
- `MapConfig` calls `playSound()` when a map is entered, unless `MainManager.isFighting`. The fight module is a separate DLL,
  so the battle side is not in this file; what it shows is that a map's theme does not start during a fight, and that the
  theme of the map one returns to starts from its beginning, since `stopSound` drops the playing `Sound`.
- `AnimateManager` stops the theme for a full-screen movie and plays it again afterwards; `GamePlatformManager` stops it for
  a mini-game. Panels (bag, shop, star map, encyclopedia) do not touch it: they open over the map, whose theme plays on.
- `SoundManager.setIsPlay` is the client's music switch; the remake's mute and music volume take its place.

## The period map table

`MapXMLInfo_xmlClass` (DefineBinaryData 160, SHA-256 `1a62b662…f3198c`) lists 657 maps, 616 with a `sound`. Each game
region is looked up by its `originalMapId`; the two authored regions without a map of their own (雷伊特训湖边 and 死亡之河)
use their planet's map, as their artwork does.

Three maps of the game are newer than the table. Their theme comes from the current official table (`map_config.json` of
`Nattsu39/seer_data@a00bcdd`, the snapshot the catalog pins):

| Map | Current theme | Period status |
| --- | --- | --- |
| 1063 降世山巅 | `BGM_104` | Period file: the 2013 table gives it to 巨型陨石 (415, 457), 迷雾森林 (697), 光明顶 (700) and others |
| 1303 黑白森林 | `BGM_009C` | Period file: the 2013 table gives it to 黑白森林 (407), the same scene before its later re-issue |
| 948 祸乱之源 | `BGM_10032` | Later music: its ID3 tag names Logic 10.2.2, a 2015 release |

The current table is not a substitute for the period one: it gives 52 of the game's 153 maps a later theme, among them the
ship (传送舱 `BGM_397`, 船长室 `BGM_131`) and 克洛斯星 (`BGM_206`, the theme `official-game-feel-resources.md` sampled).

## Where the files come from

| Candidate | Result |
| --- | --- |
| Official Flash resource server, `https://seer.61.com/resource/map/sound/<id>.mp3` (the URL `getMapSound` builds) | All 90 answer HTTP 200 with `audio/mpeg`. Every `Last-Modified` is 2020-06-10, a server migration rather than a content date. **Used.** |
| Wayback Machine | No capture of any map theme before 2024: the CDX index has only `BGM_001A` (2024-08-13); `BGM_003A`, `BGM_004`, `BGM_007` have none. |
| Local caches | `.cache/map-assets` holds map 73 only, `.cache/original-fight` and `.cache/skill-effects/sources` battle files; none holds map music. `../analysis` holds the 2013 DLL above. |
| Current Unity bundles (`newseer.61.com`, where the battle theme came from) | They carry the current client's music, re-encoded (the sampled `BGM_206` decodes as mono 22,050 Hz); a period theme would be a second-generation copy at best. Not used. |

The files' own metadata matches the period tool chain, though no archive can prove byte identity with the 2013 files:
87 carry only an ID3v2.3 genre frame `(12)`, two (`BGM_123`, `BGM_133`) Windows Media Player `PeakValue`/`AverageLevel`
frames; 35 are 11,025 Hz at 32 kbps, 52 are 22,050 Hz at 64 kbps and two (`BGM_001A`, `BGM_003A`) 44,100 Hz at 128 kbps.
The one later file, `BGM_10032`, is ID3v2.2 written by Logic 10.2.2 with iTunes tags, at 44,100 Hz and 64 kbps: the server
keeps each file's own encoding.

### Size, encoding and packaging

The 90 files total 25,845,055 bytes; the shortest is `BGM_024` (3.2 s, 25 KB, the fortress loop), the longest `BGM_003A`
(90.4 s, 1.4 MB, the ship). They ship **unchanged**: most are already 32 or 64 kbps, so an AAC copy would barely shrink and
would lose quality, and unchanged bytes keep the official SHA-256 as their provenance. Every browser the package supports
decodes MP3 in Web Audio.

They follow the repository's rule for large media: `public/audio/scene/*.mp3` is ignored by Git (as `public/audio/*.m4a`
is) and travels with the other runtime assets. `npm run package` stages every file of `public/` into the package, so the
themes ship. `public/audio/source-manifest.json` (`sceneMusic`) pins each file's URL, size, format, duration and
SHA-256; `tools/assets/download_scene_music.py` fetches missing files from the official server and refuses any whose hash
differs.
The release gate (`tools/verification/payload.mjs`) reads the theme URL template `/audio/scene/${…}.mp3` with the track
names the build holds, so a package missing a theme fails it.

## Design

- **One source.** `data/scene-music.json` maps each original map ID to its theme. `sceneTrack` (`src/domain/world/scene-music.ts`)
  picks the region's map, else its planet's; `locationTrack` (`locations.ts`) binds it to the table for a location.
- **One owner.** `GameAudio` (`src/shared/audio/game-audio.ts`) plays all music: the battle theme during a battle, the scene's
  world theme otherwise. `setSceneMusic(track)` names the theme of the scene on screen. Its async generation guard is kept: a
  load that finishes after the wanted music changed starts nothing and asks again for what is wanted now.
- **The scene.** `useShellAudio` keeps the location the world map reports (`WorldMap`'s `onSceneChange`), or, while a campaign
  stage is open, the campaign's location (`campaignLocation`, the first encounter's, where its backdrop comes from). Windows
  and panels open over the scene and leave its theme alone, as the original's panels did.

| Moment | Music |
| --- | --- |
| Before the first click or key | Nothing loads or plays (the browser's gesture unlock). |
| A map with the same theme | The theme plays on. |
| A map with another theme | The playing theme fades out over 1 s (the original's 0.03 per 30 ms); the new one then starts from its beginning. A theme replaced before it began is dropped at once. |
| Battle | The world theme fades out over 1 s, then the battle theme loops. The battle loading screen keeps the world theme. |
| After a battle | The battle theme stops; the world theme of the scene starts over from its beginning, as the original's map theme did after a fight. |
| Hidden tab, mute, music volume 0 | The music stops and keeps its position; it resumes there. Nothing loads while hidden, muted or at 0. |
| Volume | The existing music volume (`musicVolume`, the slider now labelled 音乐 instead of 战斗音乐) covers both themes; settings keep their storage key. |

Loading is lazy: only the wanted theme is fetched, one at a time, so rapid map changes fetch only the theme wanted at the
end. Decoded audio is large (a minute of decoded stereo is about 25 MB), so the two most recent world themes stay decoded
and older ones are fetched again when needed; the battle theme and the cues stay as before.
