# Experience revision 0.3

The accepted objective is an interactive Chinese single-player game in development mode. The previous desktop package is not the delivery target. The recovered catalog, raising engine and battle engine remain the foundation; changes concentrate on the scene, classic interaction sequence, visible statistics, resource loading and the reported retreat defect.

## Focused verification

`npx tsc --noEmit` passed on the integrated source. `tools/verification/battle-v3.ts` and `tools/verification/game-v3.ts` passed as Node bundles under the ignored `artifacts/presentation-v3/` directory. The existing large source test suites were not rerun merely to reconfirm the old delivery.

The real-interface checks used the main development origin for the reported fainted-active retreat and learning-value edit, then restored the original party lead, values and health. Further acquisition/confirmation checks used a separate development origin and isolated save so they did not replace the player's current progress. Browser snapshots and screenshots verify visible interactions; catalog/controller checks verify their data effects. The native packaged webview was not part of v3 verification.

## Retained content boundaries

The catalog contains 1,483 species, 5,325 skills and 162 encounters. Original official portraits are retained for all species, including 1,340 raster portraits with their original resolution limits. The maps are authored remake scenery. The command structure follows the official classic guide recorded in `battle-presentation.md`; unavailable historical screenshots prevent a pixel-exact original-interface claim.

Forty-seven of the 48 original trait records have usable hooks. The Hui Xin/Mian Bao critical-rate increments are explicit remake calibration, not verified original numerical rates; see `critical-traits.md`. Luan Wu's multi-target effect remains outside the single-opponent battle scope. Fifth-skill, soul-mark and engraving datasets remain intentionally empty, as previously agreed. The documented floor-69 tower substitution remains in use. None of the representative checks certify all 162 encounters or historical server equivalence.
