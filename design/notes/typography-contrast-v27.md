Date: 2026-10-04. Scope: live typography, scene name labels, laboratory hover decoration and settings contrast in `src/world.css`, `src/game-shell.css` and `src/components/AudioSettings.css`. ## Source boundaries and typography

The source investigation establishes mixed original typography, rather than a uniform sans-serif font. Decompiled `BasePeoleModel.as` sets ordinary player names to Songti (`宋体`), size 12, centered alignment and 0.5 letter spacing. It creates a simple sprite container without a rectangular backing. The ordinary player name retains the base text field's black color and has no explicitly authored glow. Decompiled `NpcModel.as` and `RobotModel.as` inherit Songti, set size 14 and blue (`0x0000ff`), and apply a white glow with blur 3 and strength 5. These source paths also create no boxed name backing. The separate annual/VIP ornament is outside the ordinary label treatment.

The source worker also found 177 dynamic UI EditText records using embedded font 7 (`SimSun`), a size-14 yellow map-name field and size-12 white skill and PP fields. Several static Chinese icon labels are already vector paths; their appearance is preserved in the original assets. This evidence does not justify claiming that all original text was sans-serif.

Live text follows the recovered SimSun/Songti source family, with `SeerSimSun, SimSun, 宋体, Songti SC, STSong, serif` as the source-family fallback stack. The source worker confirms that `UI.swf` font 7 has an empty glyph and code table, so it cannot supply a usable Chinese webfont; the other embedded SimHei subsets contain only two or four glyphs and are not general runtime fonts. The integration audit recovered the installed Office SimSun face and serves an exact copy only from ignored developer cache through a DEV-only stylesheet. Chromium confirms the face is loaded. The historical client font binary is still unverified. The parent's earlier inference that the user wanted sans-serif text was corrected before handoff. The original font evidence takes precedence. Original embedded vector lettering is retained. Dynamic map-name text follows the recovered size 14, normal weight and yellow color. Shared management and atlas font-family overrides prevent their earlier Arial stacks from superseding the source family.

Player and NPC names no longer have invented rounded rectangles. Player names use centered black text, with the source's 0.5 letter spacing. NPC names use blue text and a narrow white text glow matching the recovered source filter. Ordinary creature labels retain their existing contrasting text treatment and level information, without rounded backing cards.

## Laboratory labels and settings

The original fusion and breeding titleplate backgrounds remain in the scene artwork. Those source plates are empty, so their live labels remain visible in source-style white Songti, size 12, normal weight and zero letter spacing, with a narrow blue text outline. The original empty plate backgrounds provide the backing rather than an added floating card. Accessible button names and interactions are preserved. The authored equipment outline and its cyan hover glow are removed, along with the machinery-sized focus border. The shop's retained text label has no floating card or rounded backing. Keyboard focus and hover can change its text color without drawing an equipment outline.

Settings now use a uniform light content well and navy text across sound, save transfer, developer tools, full-screen controls and the explanatory notes. Buttons use a readable blue-on-light bevel. Audio labels, legend, percentages and muted explanatory text all share the same navy-on-light treatment. Native sliders and checkboxes retain their controls and blue accents.

A selector scoped to windows containing `.settings-console` applies the recovered `Panel_Background` as an unfilled nine-slice border image, using the recovered source scale grid: top 35, right 55, bottom 37 and left 54 source pixels, rendered at 12 and 16 CSS pixels. Its source corners and metallic rails remain outside the light content area instead of stretching deep strips of saturated cyan behind text. The settings body retains vertical scrolling, contained overscroll and a bounded flexible height. Other scene-window appearance, root layout, modal overlay and modifier selectors are unchanged by this worker.
