# Encounter labels, sparse special creatures, and scene return

Scene creature labels now show the name and exact encounter level instead of the redundant wild-status label. Each instance receives a stable level within its region's existing range. Its dialogue and battle action use that same value; they no longer start every instance at the region's minimum level.

The sparse encounter registry includes YiYi, Bogu, and the small luminous bee alongside the existing four rare encounters. Each listed species appears once per scene. Ordinary species still fill populated scenes, and habitats containing only sparse species do not expand to six duplicates. This is an explicit scene-density policy, not a historical spawn-rate simulation.

Entering a battle clears the map's selection, detail view and pending approach state. The map component remains mounted, preserving its region, background and player position. Once the battle's last presentation frame completes, a brief outcome display closes combat automatically. The original encounter dialogue is not restored, and the result is repeated as a short scene message. The same finish path handles victory, capture, loss and retreat; campaign battles return to their initiating stage scene.

Verification used a separate browser save on the development origin at port 1426. Forest inspection showed one YiYi with a Lv.15 label. Retreat and successful capsule capture returned automatically to the exact original forest background and player coordinates, with no battle or encounter dialogue remaining. A normal grassland scene displayed six Pippi across levels 3–6; the selected Lv.6 instance's dialogue and combat header both used level 6. Defeating that instance returned automatically to the original grassland background and exact player coordinates, with no old dialogue or combat element. Structured before/after observations and a screenshot are retained under ignored `artifacts/encounters-v15/`. TypeScript and whitespace checks passed. No production build, native package, broad historical suite or player-save replacement was performed.
