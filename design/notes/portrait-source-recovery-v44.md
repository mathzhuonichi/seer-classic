# V44 original portrait source recovery

The source pass selects faithful original artwork for 1,482 of the 1,483 catalog IDs. Species 910 is the only recovered source whose main body is principally bitmap artwork; its separately approved conservative AI reconstruction is now selected through `public/portraits/hd/manifest.json`. The 1,296-by-1,213 transparent PNG was visually reviewed by the integrating task, and is explicitly classified as an AI redraw. This source pipeline performs no AI redraw and never enlarges the original H5 PNG to claim new detail.

The runtime source selection is 1,336 pure SVGs, seven SVGs with original bitmap effects, 70 direct original-SWF renders at 4x, and 69 direct renders at 2x. All 1,483 original H5 PNG files and all 143 previously shipped SVG files remain unchanged. Seven of those retained SVGs are superseded at runtime by source renders because their effects differ materially from the original Flash renderer. The stored SVG set has 1,350 files, including those seven retained alternatives.

Static frame 1 of that symbol is used; no ActionScript is executed. The separate front-view resource is not substituted.

The ignored `.cache/portrait-v44/toolchain/manifest.json` pins official JPEXS FFDec 26.3.0 and Temurin JRE 17.0.20.1+1. Native calibration uses `@resvg/resvg-js` 2.6.2, installed only in the ignored tool cache. Independent spot comparisons also use librsvg 2.62.2. Pillow is installed in the user's base uv-managed Python environment. Runtime game dependencies were not changed.

The original batch was paused after the user reported repeated background Java applications. Both Java system properties `java.awt.headless=true` and `apple.awt.UIElement=true` now precede `-jar`; FFDec receives `-cli`. A bounded source-1 export verified that the frontmost application stayed unchanged and no Java GUI application was registered before batch work resumed. `.cache/portrait-v44/quiet-launch-check/verification.json` records that check. Valid raw exports are reused and progress is written atomically after each asset.

The cumulative 1,340-asset SVG/2x reference export took 2,039.961 seconds, including concurrent verification work. The complete ignored source/tool/render cache occupied approximately 988 MiB at handoff. Published SVG files total 99,498,398 bytes, and the 139 selected direct-render PNGs total 20,732,552 bytes.

## Selection and verification

A candidate SVG is measured from its own rendered alpha, using an expanded viewport before cropping. Large source canvases are bounded using transformed geometry before rendering. Final transparent margins are checked again. All 1,324 pure-SVG and 15 reviewed mixed-SVG candidates passed this nonempty, complete-silhouette check. Bitmap-body 910 is excluded from those candidates.

The published SVG's paths, transforms, fills, gradients, original bitmap payloads, and other geometry are compared against the raw original export after removing only FFDec metadata and root viewport dimensions. The geometry digest must match exactly. Active SVG content, event handlers, and external image references are rejected. Original bitmap effects are retained as embedded original PNG data.

Direct FFDec first-frame pixels are compared with native SVG pixels after separate alpha cropping. Comparison-only normalization uses a 320-by-320 canvas; no normalized image is delivered. Acceptance requires aspect error at most 0.025, alpha intersection-over-union at threshold 16 at least 0.965, and average RGB error on both white and black backgrounds at most 7.5/255. The H5 snapshot comparison is recorded separately because animation phases can differ.

When SVG rendering does not preserve the source appearance closely enough, a direct 4x original-display-list PNG is tested against the direct 2x reference. Source-scale comparisons permit RGB error up to 10/255 with the same alpha and aspect thresholds. If 4x changes low-alpha Flash effects, the untouched 2x source pixels are cropped with transparent padding instead. Those files retain the actual 2x scale in their metadata. The smallest selected direct-render/native-H5 longest-visible-edge ratio is approximately 1.94; source vectors, rather than H5 raster pixels, provide the extra detail.

The previously shipped filtered SVGs 1318, 1380, 1388, 1390, 1448, and 1483 remain selected. Species 799, 1248, 1295, 1305, 1421, 1438, and 1461 use source renders after comparison. The original 799 viewport also clips a small amount of filter alpha in independent librsvg rendering. All original SVG bytes are preserved.

Fifteen mixed sources contain original vector bodies with bitmap electric or flash effects: 164, 165, 166, 284, 285, 286, 310, 311, 312, 409, 410, 411, 442, 443, and 444. Removing the images leaves the complete vector bodies; the retained vector-alpha coverage is approximately 71–96 percent. Seven pass the SVG pixel gate, while eight use direct source PNGs to preserve their filters. Bitmap effects retain their native information limit. In contrast, removing bitmap images from 910 leaves only an orange ellipse, with about 6.51 percent vector-alpha coverage.

Species 311 is a bounded-render exception. Its official H5 PNG contains almost only an eye, while the original SWF supplies the complete creature. The raw SVG canvas exceeds 137 million pixels and caused FFDec's PNG allocation to fail at the bounded Java heap. The original SVG geometry was cropped safely without allocating that canvas. Independent librsvg/resvg agreement is alpha IoU 0.99024 and mean RGB error 1.60/2.63 on white/black. The original H5 file remains intact.

## Reproduction records and publication

The scripts under `tools/assets/` separate source retrieval/export, classification, viewport calibration, pixel validation, direct source rendering, and publication. The main ignored records are `sources.json`, `full-export.json`, `calibrated-candidates.json`, `mixed-candidates.json`, `calibration-report.json`, `mixed-calibration-report.json`, `mixed-classification/report.json`, `mixed-source-independent.json`, `source-quality-report.json`, `retained-filter-selection.json`, and `source-render-candidates/manifest.json` under `.cache/portrait-v44/`.

The baseline for the 143 original SVGs and stable layout is Git revision `00a93ec`. `publish_source_portraits.py --check-only` validates all source/output digests, geometry, selections, and complete ID coverage before writing public files. Publication then regenerates profiles with `build_art_profiles.py --preserve-layout`. All 1,483 evolution-root, stage, and physical-scale triples remain unchanged; every selected runtime path exists. The stable-layout digest is recorded in `public/portraits/source-audit.json`.

The public vector and source-render manifests contain individual provenance and dimensions. `public/portraits/source-audit.json` records the source-only selection plus separate `runtime_counts` and `runtime_overrides` fields. The AI override for 910 has its own prompt, review, and digest in `public/portraits/hd/manifest.json`; it is not original recovered geometry. Profile regeneration checks the override digest, measures its alpha, and preserves evolution root, stage, and physical scale. Browser appearance is checked by the integrating task through the shared creature renderer; this source audit does not claim formal pixel equivalence across every browser or unlimited resolution for bitmap effects and PNG deliveries.

The newly generated SVG and PNG payloads remain local and gitignored under `public/portraits/vectors/` and `public/portraits/source-renders/`, following the workspace rule for large generated data. The previously tracked 143 SVGs remain tracked. Manifests, profiles, source recovery tools, and this audit are tracked; they identify the generated files by source/output digest. The verified local runtime and packaging build can use these generated files. A fresh checkout must recover the generated assets before it can reproduce the same complete offline portrait coverage.

Final static checks found no missing runtime paths and no changes to evolution-root, stage, or physical-scale triples. TypeScript compilation passed. Three contact sheets compare H5 snapshots, source first poses, and published files for species 31, 164, 216, 300, 311, 342, 799, 1000, and 1461; their original designs and orientations were inspected visually. The sheets are verification-only images under the ignored cache and are not delivered game artwork.
