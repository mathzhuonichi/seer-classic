# Original official map backgrounds

These 133 offline backgrounds retain original official Seer artwork. The parent `original-manifest.json` maps original numeric map IDs to their paths, source URLs, dimensions, hashes, and extraction records.

The JPEG and PNG files preserve the official H5 source bytes. The SVG files are static exports of the original Flash `bg_mc` background layer, with the original viewport registration retained. Some current official sources contain later map redesigns. Animated scenery and scripted map content are separate from these background files.

See `design/notes/original-map-asset-delivery.md` and `tools/assets/download_original_maps.py` for source and reproduction details. No original artwork is claimed as locally authored.
