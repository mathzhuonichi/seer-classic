# Laboratory interface emblems

These three SVGs are locally authored interface emblems, not recovered original Seer machine artwork. They use restrained cyan glass, blue-gray metallic edges, and amber indicators to match the official laboratory background.

The original machinery remains visible in `/maps/original/5.jpg`: the left holographic platform hosts fusion, the rear paired chambers host breeding, and the central wall console hosts the item shop. `WorldMap.tsx` places independent interaction footprints over those devices, with the emblems and short labels serving as access cues. The original background file is not edited, cropped, or replaced.

The cached official resource manifest, `.cache/map-assets/5/map_5_9d550ede.json`, lists only a road layout, an EXML skin, and the single background image. No independent machine bitmap is listed there. This is a statement about that inspected source table, not a claim that no original machine assets exist elsewhere.
