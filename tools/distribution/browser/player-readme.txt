赛尔经典 · Seer Classic — 请先阅读（浏览器版）

赛尔经典（Seer Classic）是非官方的爱好者重制版，与上海淘米网络科技有限公司无关。游戏中的原版美术、音效、动画与 SWF 素材版权归 © 上海淘米网络科技有限公司所有。本作免费提供，仅供个人怀旧与学习，不得出售或用于任何商业用途。

这是浏览器版：游戏在你自己的浏览器里运行，同一个文件夹在 Windows 和 Mac 上都能用。不需要安装，也不需要网络。

一、解压
- 解压时请预留约 6 GB 可用磁盘空间（ZIP 约 2.8 GB，解压后约 3.1 GB；解压完成后可以删除 ZIP）。
- 必须完整解压整个 ZIP，不要在压缩包窗口里直接双击运行。解压出的文件夹里应有 game 和 runtime 两个文件夹、server.mjs 和两个“启动游戏”文件。
- 如果启动时提示“游戏文件不完整”，请删除这个文件夹，重新完整解压一次。

二、Windows 10 / 11（64 位）
1. 解压前，在下载的 ZIP 文件上右键 > 属性；如果下方有“解除锁定”，勾选后点“确定”。这样启动时就不会出现安全警告。
2. 解压到本地文件夹，例如 C:\Games。不要解压到 OneDrive 同步的“桌面”“文档”或“图片”中：同步会上传约 3 GB 文件，还可能让文件只留在云端，游戏就读不到了。
3. 双击“启动游戏-Windows.bat”。如果出现“Windows 已保护你的电脑”，点“更多信息 > 仍要运行”；如果出现“打开文件 - 安全警告”，点“运行”。
4. 会出现一个黑色窗口，随后游戏在 Microsoft Edge 的独立窗口中打开（没有 Edge 时用默认浏览器）。推荐使用 Edge 或 Chrome。
5. 如果 Windows 防火墙询问是否允许 Node.js 访问网络，可以点“取消”：游戏只在这台电脑内部通信。

三、macOS 13.5 或更新（Apple 芯片或 Intel 芯片的 Mac）
1. 双击 ZIP 解压，把解压出的文件夹放到任意位置，例如“文稿”。
2. 第一次打开时：按住 Control 键点按（或右键点按）“启动游戏-macOS.command”，选择“打开”，再在对话框中点“打开”。
   如果对话框里没有“打开”按钮（macOS 15 及更新版本）：先双击它一次并关闭提示，再打开“系统设置 > 隐私与安全性”，在页面下方点“仍要打开”，然后确认。
   以后直接双击即可。
3. 如果“终端”询问能否访问“下载”“文稿”或“桌面”文件夹中的文件，请点“好”（或“允许”）：游戏要读取这个文件夹里的文件。
   如果点了“不允许”，请到“系统设置 > 隐私与安全性 > 文件和文件夹 > 终端”中打开对应文件夹的开关。
4. 会打开一个“终端”窗口，随后游戏在 Google Chrome 中打开（没有 Chrome 时用 Microsoft Edge，都没有时用默认浏览器）。
   推荐使用 Chrome 或 Edge：如果连续 7 天用 Safari 上网却没有打开这个游戏，Safari 可能会删除游戏的网站数据，存档也就没了。只能用 Safari 时，请每次玩完都导出存档（见第五节）。

四、玩的时候
- 黑色窗口（Windows）或“终端”窗口（macOS）就是游戏的服务程序：玩的时候不要关闭它。不玩时直接关闭这个窗口即可停止游戏（在 macOS 上也可以在其中按 Ctrl+C；在 Windows 上按 Ctrl+C 后窗口会问“终止批处理操作吗(Y/N)?”，输入 Y 再按回车即可）。
- 游戏地址是 http://127.0.0.1:1426/。如果浏览器窗口被关掉了，再双击一次启动文件即可。
- 同一时间只能有一个程序使用 1426 端口。如果提示端口被占用，请先关闭另一个游戏窗口或占用它的程序。
- 如果 Windows 提示“不允许游戏使用端口 1426”，请重启电脑；仍然不行时，按黑色窗口里的说明以管理员身份运行 net stop winnat 和 net start winnat。

五、存档在哪里
游戏自动保存。存档保存在浏览器里（网站 http://127.0.0.1:1426 的数据），不在这个文件夹里：
- 请一直用同一个浏览器玩：换一个浏览器（例如从 Edge 换到 Chrome）就看不到原来的存档。浏览器的无痕或隐私窗口不会保留存档。
- 在 Mac 上游戏优先用 Chrome 打开。如果你以前在 Safari 中玩过：启动游戏后把地址复制到 Safari 中打开，在“设置”中导出存档，再回到 Chrome 的游戏中导入。
- 清除浏览器的“浏览数据”“Cookie 和网站数据”会删除存档。
- 删除或更换这个游戏文件夹不会删除存档：新版本解压后照样启动，同一个浏览器里的存档还在。
- 收到新版本后，请只用新版启动（旧版文件夹可以删除）。不要再用旧版打开：新版可能升级了存档，旧版读不懂时会把它原样另存（在“设置”的“无法读取的存档”中导出后，可以在新版中导入），然后开始新的旅程。
- 请经常在游戏的“设置”中点“导出存档”，把得到的 .json 文件保存好。换电脑、换浏览器或清除了浏览数据后，在“设置”中点“导入存档”选择这个文件即可恢复。
