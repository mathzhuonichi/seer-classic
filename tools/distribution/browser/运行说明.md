# 赛尔号经典版 0.0.1 运行说明

赛尔号经典版（游戏里显示为“赛尔经典 · Seer Classic”）是一个单机游戏，在你自己电脑的浏览器里运行。
不用安装；下载完以后也不需要联网。

## 三步开始

1. 把下载的 ZIP 完整解压（见下面的“解压”）。
2. Windows 双击“启动游戏-Windows.bat”，Mac 双击“启动游戏-macOS.command”。
3. 游戏会在浏览器里打开。玩的时候不要关闭同时出现的另一个窗口：Windows 上是一个黑色窗口，Mac 上是“终端”窗口。

## 需要什么

- Windows 10 或 Windows 11（64 位）；或者 macOS 13.5 及更新版本的 Mac（Apple 芯片和 Intel 芯片都可以）。
- 约 7 GB 可用磁盘空间：ZIP 和解压出来的文件夹各约 3 GB。解压完成后可以删除 ZIP。
- 推荐用 Google Chrome 或 Microsoft Edge 玩（Windows 自带 Edge）。

## 解压

1. Windows：在下载的 ZIP 上点右键，选“全部解压缩”，再点“提取”。不要双击打开 ZIP 后在里面直接运行。
2. Mac：双击下载的 ZIP，旁边会出现解压好的文件夹。
3. 解压可能要几分钟。解压好后打开 SeerClassic-0.0.1 文件夹，里面有 game、runtime 两个文件夹和两个“启动游戏”文件。
4. 请保持这个文件夹完整，不要删除或移出里面的文件。整个文件夹可以移到别的地方。

## Windows：开始玩

1. 在 SeerClassic-0.0.1 文件夹里双击“启动游戏-Windows.bat”（如果看不到 .bat，就是名为“启动游戏-Windows”的文件）。
2. 如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。如果出现“打开文件 - 安全警告”，点“运行”。
3. 会出现一个黑色窗口，随后游戏在 Microsoft Edge 的独立窗口中打开（找不到 Edge 时用默认浏览器）。
4. 黑色窗口就是游戏的服务程序：玩的时候不要关闭它，可以把它最小化。
5. 不玩了，关闭黑色窗口即可停止游戏。
6. 如果在黑色窗口里按了 Ctrl+C，它会问“终止批处理操作吗(Y/N)?”：游戏已经停了，输入 Y 再按回车，窗口就会关闭。
7. 如果防火墙询问是否允许 Node.js 访问网络，点“取消”也可以：游戏只在这台电脑内部通信。

## Mac：开始玩

1. 在 SeerClassic-0.0.1 文件夹里双击“启动游戏-macOS.command”。
2. 第一次打开时，macOS 会拦下它（这个启动文件没有签名）。按下面第 3 或第 4 步放行一次，以后直接双击即可。
3. macOS 13 或 14：按住 Control 键点按（或右键点按）这个文件，选“打开”，在对话框里再点“打开”。
4. macOS 15 或更新：先双击一次，在提示框中点“完成”；再打开“系统设置 > 隐私与安全性”，在页面下方点“仍要打开”，然后再确认一次（可能要输入开机密码）。
5. 如果“终端”询问能否访问“下载”“文稿”或“桌面”文件夹中的文件，请点“好”或“允许”。
6. 会打开一个“终端”窗口，随后游戏在 Google Chrome 中打开；没有 Chrome 时用 Microsoft Edge，两个都没有时用默认浏览器。
7. 玩的时候不要关闭“终端”窗口。不玩了，关闭它即可停止游戏（如果问是否终止进程，点“终止”）。

## 存档

- 游戏自动保存。存档存在你玩游戏的那个浏览器里（网址 http://127.0.0.1:1426 的网站数据），不在游戏文件夹里。
- 只有同一台电脑上的同一个浏览器能看到这份存档：换浏览器、用无痕或隐私窗口都看不到。
- 清除浏览器的浏览数据（尤其是 Cookie 和网站数据）会删掉存档。
- 备份：点屏幕下方工具栏右边的“设置”，再点“导出存档”。浏览器会下载“赛尔号-星际存档.json”，请把它保存好。
- 恢复，或搬到别的电脑、别的浏览器：在那里启动游戏，点“设置”，再点“导入存档”，选这个文件（战斗中不能导入）。
- 在 Mac 上只用 Safari 的话：如果连续 7 天用 Safari 上网却没打开这个游戏，Safari 可能删除游戏的网站数据，存档也就没了。请每次玩完都导出存档。
- 更新到新版本：先关闭旧版本的黑色窗口（或“终端”窗口），再解压新的 ZIP，以后只启动新的文件夹（旧文件夹可以删除）。用同一个浏览器玩，存档会接着用。
- 如果你之前收到过 0.9.0 版：0.0.1 是它之后重新编号的新版本。先关闭 0.9.0 的黑色窗口（或“终端”窗口），再启动 0.0.1，以后只用 0.0.1。

## 遇到问题

- 提示“端口 1426 已被其他程序占用”：游戏必须用这个端口（存档跟着它）。关闭占用它的程序，或重启电脑后再启动。
- 提示“已经在另一个窗口中运行，正在打开浏览器”：游戏已经开着，会直接打开浏览器。Windows 上这时黑色窗口会一闪就关，浏览器照常打开。正在玩的版本号在游戏“设置”最下面的“关于”里。
- 提示“不是这个文件夹的 0.0.1 版”：开着的是另一个版本，所以没有打开浏览器。先关闭之前的黑色窗口或“终端”窗口，再启动这个文件夹。
- 提示“不允许游戏使用端口 1426”：先重启电脑。Windows 上如果还不行，照黑色窗口里的说明，以管理员身份运行 net stop winnat 和 net start winnat。
- 浏览器没有自动打开：自己打开 Chrome 或 Edge，在地址栏输入 http://127.0.0.1:1426 再按回车（黑色窗口或“终端”窗口要开着）。
- 提示“找不到游戏文件”“游戏文件不完整”或“找不到游戏的运行环境”：删除这个文件夹，把 ZIP 重新完整解压一次。
- Mac 提示 macOS 不允许“终端”读取游戏文件：打开“系统设置 > 隐私与安全性 > 文件和文件夹 > 终端”，打开游戏文件夹所在位置（例如“下载”）的开关。
- Windows 提示“系统拒绝读取游戏文件”：把整个游戏文件夹移到 C:\Games 这样的本地文件夹再启动。
- 很卡或加载很慢：第一次启动和第一次进入战斗要多等几秒。一直很卡的话，关闭其他程序，用 Chrome 或 Edge 玩，并把游戏文件夹放在电脑本地的硬盘上（不要放在 U 盘、网络盘或 OneDrive 同步的文件夹里）。
- 提示“游戏服务意外停止了”，或遇到其他问题：把黑色窗口（或“终端”窗口）和浏览器画面截图，发给提供游戏给你的人。
