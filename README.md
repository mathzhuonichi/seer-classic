# Seer Classic

A local macOS, single-player Seer remake focused on PvE battles and monster raising. The interface is Chinese. The original Claude battle and raising engines are retained, with the complete recovered classic catalog and original portraits.

## Content and mechanics

The retained catalog contains 1,483 species and 5,325 skills. The current runtime loads 180 encounter definitions from `data/bosses`, including later recovered campaigns and the authorized solo Seville adaptation: SPT bosses, legendary challenges, towers and task battles. Three additional remake trainers load separately from `data/trainers` and do not participate in acquisition routing. All 1,483 species have their original official portraits and battle motion available offline. Bosses are available at any time. Boss victories grant essence items that hatch immediately. Ordinary wild creatures are obtained through capsules in battle; defeating them does not automatically recruit them. Other difficult acquisition routes become named recruitment challenges or explicit task rewards.

The classic trait registry preserves 48 original client records. Forty-seven have implemented battle hooks. Hui Xin and Mian Bao use the explicitly labeled remake calibration described in `design/notes/critical-traits.md`; their historical numeric probabilities remain unverified. Luan Wu requires multi-target combat and remains unavailable in the current single-opponent mode. New monsters receive one of the implemented traits. Fifth skills, soul marks and engravings have typed extension interfaces and save fields; their datasets are intentionally empty for later completion.

## Source and decisions

`approved-plan.json` records the user's current decisions. `design/` contains the original foundation documents, which predate those decisions. `battle/core/` and `raising/` contain the recovered original implementations. `tools/assets/` records catalog, portrait and trait provenance.

The original floor-69 tower record had an empty opponent team. Its original copy is preserved in `design/source-snapshots/`. The playable encounter uses the four documented floor-70 species at the preceding floor's level and HP; this is an explicit remake choice.

Development prioritizes the integrated playable result. Existing large test suites were not repeated merely to reconfirm earlier reports. Current delivery checks cover TypeScript, focused retreat/critical-hit/stat-edit regressions, and representative real-interface walking, management, battle, reward, essence-hatching and quest flows. The revision-19 follow-up adds a freshly verified production browser export; no updated native application has been packaged.
